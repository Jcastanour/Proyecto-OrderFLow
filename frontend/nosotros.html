OrderFlow conecta directamente al comensal con la cocina del barrio. Sin comisiones abusivas, sin filtros de revista. Hecho con AWS Serverless por estudiantes del Bootcamp BeTek Cloud — Grupo 02, Proyecto 04.

Cómo funciona

01

Pides

Eliges tus platos en la carta, agregas al carrito y confirmas con tu nombre y dirección. Listo.

02

Cocinamos

El pedido entra al tablero operativo de la cocina. Cuando esté listo, queda disponible para repartidores cercanos.

03

Te llega

Un repartidor lo toma y lo lleva. Puedes seguir el estado en tiempo real desde tu sección "Mis pedidos".

Construido sobre AWS Serverless

Sin servidores que mantener. Cada componente escala solo y se cobra solo cuando se usa.

API · Cómputo

API Gateway HTTP recibe peticiones y dispara Lambdas en Python que procesan cada pedido.

Datos

DynamoDB NoSQL con latencia de milisegundos y modelo pay-per-request.

Eventos

EventBridge + SQS + SNS desacoplan las notificaciones. Si mañana sumamos SMS o Slack, lo enchufamos sin tocar el resto.

Frontend

HTML + Vanilla JS + CSS modular. Servido como sitio estático desde S3.

IaC

Toda la infraestructura está definida en Terraform. Crear y destruir el ambiente toma minutos.
